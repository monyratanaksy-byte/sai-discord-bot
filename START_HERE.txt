S.A.I easy update workflow

Source folder:
/Users/monyratanaksy/Desktop/Project/sai-discord-bot

Manual Wispbyte upload zip:
/Users/monyratanaksy/Desktop/Project/sai-discord-bot-wisebyte.zip

Manual Katabump upload zip:
/Users/monyratanaksy/Desktop/KATABUMP BOT UPLOAD - USE THIS/sai-discord-bot-katabump-update.zip

Update code:
1. Edit files in the source folder.
2. Run pnpm run package:wispbyte to rebuild the Wispbyte upload folder and zip.
3. Upload sai-discord-bot-wisebyte.zip to Wispbyte if you are using manual uploads.

Katabump update:
1. Run bash scripts/package-katabump.sh from the source folder.
2. Open the Desktop folder named KATABUMP BOT UPLOAD - USE THIS.
3. Upload sai-discord-bot-katabump-update.zip to Katabump.
4. Extract it directly into /home/container/.
5. Keep JS FILE set to src/index.js.

Persistent server data:
/home/container/data/sai-data.json

Do not delete the data folder unless you want to reset saved setup, panels, XP, tickets, coins, invites, warnings, and config.

GitHub update:
1. Commit and push this source folder to GitHub.
2. Keep .env only on your computer and Wispbyte.
3. Do not commit node_modules or zip files.

Wispbyte startup command:
if [ -f /home/container/package.json ]; then /usr/local/bin/npm install; fi; /usr/local/bin/npm start
