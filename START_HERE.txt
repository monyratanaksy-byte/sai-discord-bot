Update code:
1. Edit files in the source folder.
2. Run pnpm run package:wispbyte to rebuild the Wispbyte upload folder and zip.
3. Upload sai-discord-bot-wisebyte.zip to Wispbyte if you are using manual uploads.

Katabump update:
1. Run bash scripts/package-katabump.sh from the source folder.
2. Open the Desktop folder named KATABUMP BOT UPLOAD - USE THIS.
3. Upload sai-discord-bot-katabump-update.zip to Katabump.
4. Extract it directly into /home/container/.
5. Keep JS FILE set to src/index.js.

Persistent server data:
/home/container/data/sai-data.json

Do not delete the data folder unless you want to reset saved setup, panels, XP, tickets, coins, invites, warnings, and config.

GitHub update:
1. Commit and push this source folder to GitHub.
2. Keep .env only on your computer and Wispbyte.
3. Do not commit node_modules or zip files.

One-command server setup:
Use /setup template

This creates the main categories, staff/verified/muted roles, welcome, rules,
verify, ticket, logs, bot commands, temp text, stats, and join-to-create voice
layout. Run it with an Administrator account.

Verification panel:
Use /verification create channel:#verify role:@Verified

It sends a professional button panel saying:
Click the button below to verify your account and unlock the rest of the server.

Give everyone a role:
Use /role give-everyone role:@RoleName

Bot profile:
Use /bot profile username:S.A.I display_name:S.A.I
Optional avatar_url can change the bot avatar. Discord rate-limits bot username
and avatar changes, so do not spam this command.

AutoMod:
AutoMod ignores members with Discord Administrator permission.

Discord User Install support:
S.A.I also has safe global utility commands that can be used through Discord
User Install where Discord allows it. These commands do not manage servers,
roles, channels, emojis, tickets, moderation, webhooks, or voice. They do not
use AI APIs, paid APIs, or required external services.

Enable User Install in Discord Developer Portal:
1. Open the Discord Developer Portal.
2. Open the S.A.I application.
3. Go to Installation.
4. Enable both Guild Install and User Install.
5. For User Install, keep the applications.commands scope enabled.
6. Keep normal bot/server install for admin, setup, mod, ticket, economy, and
   voice commands.

Deploy global user-installable commands:
pnpm run deploy:global

Keep guild commands deployed for your server:
pnpm run deploy:commands

Hidden admin-only bot speech:
Sai say Your message here
S.A.I say Your message here
Sai embed Title | Body | #57f287

These are normal message triggers, not slash commands. If S.A.I has permission
to delete messages in that channel, it deletes your trigger message first, then
sends the bot message. The trigger is also ignored by S.A.I snipe/log storage.
For the hidden effect, S.A.I needs Manage Messages and Send Messages in the
channel.

Notes, todos, reminders, and timezone settings are saved by Discord user ID in
the persistent data file. Reminders are rescheduled when the bot restarts.

/qr was intentionally not added because it would need an extra QR dependency or
external service.
